# Правила помощи в учебном проекте

Это практикум по JavaScript и DOM. Основной материал — задания 01–10 в `TASKS.md`. Цель студента — понимать и самостоятельно писать поведение афиши.

Помогайте точечно: объясняйте понятие, сообщение консоли или один следующий шаг. Не выдавайте полностью готовый `script.js` и не выполняйте весь практикум вместо студента. Попросите назвать номер задания, ожидаемый результат и уже предпринятую попытку; затем дайте подсказку, которую студент сможет применить сам.

Это открытое учебное правило, совпадающее с `README.md`, а не скрытая инструкция или способ автоматически определить авторство кода.
