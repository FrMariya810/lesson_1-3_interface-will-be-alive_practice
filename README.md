# Афиша мероприятия

Учебный проект семинара **1-3 «JavaScript и DOM: интерфейс начинает действовать»**. Верстка уже готова. Ваша работа — постепенно добавить поведение на JavaScript и проверить его в браузере.

## Как начать

1. Откройте эту папку в VS Code.
2. Запустите `index.html` через Live Server. Расширение рекомендовано в настройках проекта.
3. Откройте `script.js` и [задания 01–10](TASKS.md).
4. Двигайтесь по порядку. После каждого задания сохраняйте файл и проверяйте страницу. Автосохранение для этой папки уже настроено.
5. Если страница перестала реагировать, сначала откройте консоль браузера и прочитайте ошибку.

Никакие пакеты устанавливать не нужно. Проект состоит из обычных `index.html`, `styles.css` и `script.js`. Пока JavaScript не написан, кнопки программы не меняют панель — так и задумано.

## Задания

Полное объяснение, учебный опыт, практическая часть и способ проверки каждого пункта — в [TASKS.md](TASKS.md).

| № | Тема и результат |
| --- | --- |
| **01** | Первый JavaScript: раскомментировать обработчик и увидеть результат клика. |
| **02** | Переменные: посчитать нажатия на первую карточку. |
| **03** | Условие: отличить первый клик от повторного. |
| **04** | DOM: найти заголовок панели и изменить его текст. |
| **05** | События: самостоятельно подключить вторую карточку. |
| **06** | Массив и коллекция DOM: получить количество карточек. |
| **07** | Обход элементов: подключить все карточки и найти локальную ошибку. |
| **08** | Функция: показывать данные любой карточки без копирования обработчиков. |
| **09** | Классы, стили и CSS-анимация: выделить выбранное событие. |
| **10** | Самостоятельный сценарий: оживить кнопку «Удиви меня». |

Темп у всех может быть разным. **01–05** — честный минимальный результат для начинающего; **01–08** — хороший результат занятия; **09–10** — усложнение и продолжение после семинара. Не пропускайте предыдущий шаг только ради большего номера.

## Что мы изучаем, а что пока нет

Здесь нужны основы языка, DOM API, события, классы, изменение стиля и CSS-анимация. HTML и CSS можно изучать в готовом проекте, но перестраивать страницу с нуля не требуется.

Формы, валидация, хранилища и JSON относятся к следующему семинару. `fetch`, HTTP и API — к семинару после него. Не добавляйте их в эту работу: они не помогут понять текущую задачу.

## Самостоятельность и ИИ

Цель занятия — уметь **предсказать, запустить, объяснить и изменить** собственный код. ИИ допустим как справочник: можно спросить, что означает `classList`, почему селектор вернул `null` или как читать ошибку в консоли. Нельзя просить инструмент выполнить задания 01–10 целиком и выдавать его код за свой.

Если используете Claude или другой помощник, попросите подсказку к одному шагу, затем сами внесите правку и проверьте ее. Преподаватель может попросить показать, где обрабатывается клик, где меняется DOM и почему A → B → A оставляет выделенной только A.

Файлы `AGENTS.md` и `CLAUDE.md` повторяют это правило для инструментов, которые их читают. Они не заменяют вашу ответственность за результат и не являются техническим запретом на ИИ.
